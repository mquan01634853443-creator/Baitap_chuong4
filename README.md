# Baitap_chuong4

Ứng dụng web quán cà phê dùng Flask và Jinja2.

## Chạy ứng dụng

```powershell
python -m pip install -r requirements.txt
python -m flask --app cafe/app.py run --port 5001 --debug
```

Trang chủ: http://127.0.0.1:5001
Thực đơn: http://127.0.0.1:5001/menu
Liên hệ: http://127.0.0.1:5001/contact
